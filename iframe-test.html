ตรวจการฝังหน้า Intranet และสิทธิ์อ่านตารางจาก GitHub Pages โดยไม่ติดตั้งอะไรเพิ่ม
กลับหน้า Monthly
ยังไม่ได้ทดสอบ กรุณาเปิดหน้านี้จากเครื่องในเครือข่าย EGAT แล้วกดปุ่มลองเปิด HTTP

ต้นทาง: http://control.egat.co.th/gpddwebsite/MonthlyRequirementNonCoPage.aspx • หน้านี้ไม่ส่งข้อมูลออกไป ไม่อ่าน Cookie หรือ Session

กรอบ iframe ของ EGAT

คำเตือน: iframe อาจแสดงพื้นที่ว่าง แม้ event load เกิดขึ้นแล้ว ซึ่งไม่ได้ยืนยันว่าเว็บไซต์ EGAT โหลดสำเร็จ หากไม่แสดงให้เปิด F12 → Console เพื่อดู Mixed Content, X-Frame-Options และ Content-Security-Policy

ผลตรวจสิทธิ์การอ่านจาก Dashboard
ยังไม่ได้ทดสอบ

หากระบบแจ้ง SecurityError แปลว่า Browser ไม่อนุญาตให้ GitHub Pages อ่าน DOM ใน iframe ต่าง Origin ดังนั้นวิธี iframe ไม่สามารถ Collect อัตโนมัติได้ แม้หน้าภายในจะแสดงภาพได้
