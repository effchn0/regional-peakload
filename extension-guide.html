EGAT Monthly Requirement — Collect Data อัตโนมัติ

Extension นี้ใช้ Browser ของเครื่องภายใน EGAT เชื่อมต่อเว็บไซต์ต้นทาง แล้วอ่านเฉพาะตาราง Monthly Requirement ส่งกลับ Dashboard ในเครื่องผู้ใช้ โดยไม่ส่ง Cookies หรือ Session ไป GitHub

ติดตั้งครั้งแรก (Chrome / Edge)

  1. ดาวน์โหลด EGAT Collector Extension (.zip) แล้วแตก ZIP โดยให้มีโฟลเดอร์ extension ซึ่งมีไฟล์ manifest.json, background.js, bridge.js
  2. เปิด chrome://extensions หรือ edge://extensions และเปิด Developer mode (หากองค์กรอนุญาต)
  3. เลือก Load unpacked แล้วเลือกโฟลเดอร์ extension ที่แตกไฟล์ไว้
  4. กลับไป Monthly Requirement แล้วรีเฟรชหน้าเว็บ ดูสถานะ Extension พร้อมใช้งาน
  5. เลือกเดือนและปี กด Collect Data หน้า EGAT จะเปิดเป็น Popup และปิดเองหลังอ่านข้อมูลสำเร็จ

ข้อควรทราบ

บางเครื่ององค์กรปิดการติดตั้ง Extension จาก Developer mode หากมีนโยบายนี้ต้องให้ผู้ดูแล Browser อนุญาตหรือแจกจ่าย Extension ผ่านช่องทางองค์กรที่ได้รับอนุญาต ห้ามปิดหรือหลบเลี่ยงนโยบายความปลอดภัย

Extension จำกัดสิทธิ์อ่านเฉพาะ http://control.egat.co.th/* และสื่อสารกับ Dashboard ที่ https://effchn0.github.io/regional-peakload/ เท่านั้น ข้อมูล Collect เก็บไว้ใน Browser ของเครื่อง และ **ไม่ถูกเผยแพร่ใน Public GitHub โดยอัตโนมัติ**

การอ่านข้อมูลขึ้นกับการเข้าถึง EGAT และโครงสร้างฟอร์ม WebForms ปัจจุบัน เมื่อ Collect ล้มเหลวจะแสดงสาเหตุและไม่ใช้ Mock อัตโนมัติ
