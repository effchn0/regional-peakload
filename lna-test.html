ทดสอบ Local Network Access / CORS / Mixed Content โดยไม่ติดตั้ง Collector

ต้นทาง: http://control.egat.co.th/gpddwebsite/MonthlyRequirementNonCoPage.aspx

ใช้ทดสอบบน Chrome/Edge จากเครื่องภายใน EGAT โดยกดปุ่มเอง หาก Browser ขอสิทธิ์เข้าถึง Local Network ให้พิจารณาอนุญาตเฉพาะเมื่อเว็บไซต์นี้เป็นเว็บไซต์ที่คุณเชื่อถือ การทดสอบนี้ไม่ส่ง Cookie, Password หรือ POST ใด ๆ ไปยัง EGAT

ถ้า GET แบบ CORS สำเร็จและอ่าน HTML ได้ จะเป็นหลักฐานว่า Browser อ่านข้อมูลต้นทางได้จริงในเงื่อนไขการทดสอบนี้ หาก GET ล้มเหลว อาจเกิดจาก Mixed Content, CORS, DNS, Proxy หรือสิทธิ์เครือข่าย ซึ่งแยกสาเหตุได้เพิ่มเติมจากแท็บ Network/Console

การทดสอบ no-cors ที่ได้ opaque ไม่สามารถพิสูจน์ว่าเว็บอ่านข้อมูลได้ และไม่สามารถนำไปทำ Collector ได้ เพราะ JavaScript อ่าน Response ไม่ได้

แม้ GET ผ่าน การ Collect จริงยังต้องใช้ POST WebForms และสิทธิ์ CORS สำหรับคำขอนั้นด้วย
