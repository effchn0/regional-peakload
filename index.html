Collector รันในเครื่องภายใน EGAT เพื่อสร้างไฟล์ JSON ใน Local Repository เท่านั้น ต้องตรวจสอบแล้ว Push ไฟล์ data/ ก่อนข้อมูลจะแสดงบนเว็บไซต์ หากข้อมูลล่าช้าเกิน 1 วัน เว็บไซต์จะลองสั่ง Local Collector เมื่อเปิดเว็บ แต่จะไม่เผยแพร่เอง

ตั้งค่าการเชื่อมต่อ / นำเข้า JSON

GitHub Pages อ่าน JSON จาก data/YYYY-MM.json ตามเดือน/ปีเท่านั้น ข้อมูลไม่ใช่ Live การ Collect ใช้ Node.js ภายใน EGAT และจะไม่ส่ง Cookie, Session หรือ Hidden Fields ไป GitHub

การนำเข้า JSON เป็น Preview เท่านั้น ไม่เขียนทับไฟล์เผยแพร่หรือสร้างข้อมูล Mock
